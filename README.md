# Моя E39 — PWA журнал автомобиля

Локальное приложение для ведения истории BMW E39. Интерфейс на русском, валюта — RUB.

## Функции первой версии
- история ремонтов: дата, пробег, категория, общая стоимость, запчасти и заметки;
- каталог запчастей: бренд, артикул, количество, цена, статус и связь с ремонтом;
- топливо: дата, АЗС, литры, цена, сумма, пробег и оценка расхода;
- план обслуживания: приоритет, срок по дате/пробегу, бюджет, отметка выполнения;
- прочие расходы и сводная статистика;
- локальное хранение в браузере, экспорт JSON, импорт резервной копии и CSV;
- service worker для кэширования приложения после первого открытия.

## Запуск на Windows
1. Распакуйте папку проекта.
2. Для локальной проверки можно открыть `index.html` в браузере. Данные сохраняются в локальном хранилище этого браузера. Service worker при открытии через `file://` не работает.
3. Для PWA и офлайн-кэша опубликуйте все файлы папки на HTTPS-хостинге (например, статический хостинг). Серверная база данных не требуется.

## Установка на iPhone
1. Откройте HTTPS-адрес приложения в Safari.
2. Нажмите «Поделиться» → «На экран Домой».
3. Откройте приложение с нового значка.
4. Сделайте резервную копию в «Настройки и данные».

## Хранение и ограничения
- Все записи хранятся в localStorage того браузера/установленной PWA, где они были внесены. Автоматической синхронизации между устройствами нет.
- Очистка данных сайта или удаление приложения может привести к потере данных. Регулярно экспортируйте JSON.
- Это локальная проверка сроков при открытии приложения, а не гарантированные push-уведомления. iOS может ограничивать фоновые уведомления и выполнение кода.
- Начальный план включает работы, ранее намеченные для автомобиля. Удалите или отредактируйте их по фактическому состоянию.
